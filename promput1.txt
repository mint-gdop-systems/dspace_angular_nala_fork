I need to customize a DSpace Angular frontend. I am using the standard DSpace Angular architecture. Please follow the official DSpace 'Theme Override' best practice to customize the Navbar (by overriding the Header component and hiding the default navbar) and the Home Page (by overriding the Home News component) exactly as specified below. Do not edit any core files under `src/app/`.

Here are the step-by-step instructions, file paths, and exact code contents to implement:

### 1. Register the Theme
Define a theme named `'custom'`. In `src/config/default-app-config.ts` (or your active config files like `config.yml`), add `{ name: 'custom' }` to the `themes` array:
```typescript
  themes: ThemeConfig[] = [
    {
      name: 'custom'
    },
    {
      name: 'dspace',
      headTags: [...]
    }
  ];
```

### 2. Configure Build Styles in `angular.json`
In `angular.json`, add the custom theme style bundle under `projects -> dspace-angular -> architect -> build -> options -> styles`:
```json
              {
                "input": "src/themes/custom/styles/theme.scss",
                "inject": false,
                "bundleName": "custom-theme"
              }
```

### 3. Create Custom Theme Styles
Create the following stylesheets under `src/themes/custom/styles/` to support the theme:
